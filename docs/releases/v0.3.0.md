Switchbite's first public preview, by BiteFoundry.

**The decision layer for your agents.** A native Rust MCP plugin for worker and
model-pool recommendations, supplied-DAG validation and stateless feedback.

- Download `switchbite-0.3.0-windows-x64.zip` and verify it against `SHA256SUMS`.
- Extract the archive and run `bin/switchbite.exe config --client claude` (or
  `codex`, `cursor`, `grok`, `antigravity`, `opencode`, `generic`). Merge the
  printed snippet into your MCP settings.
- Online recommendations use host-authorized `TYPESAFE_API_KEY` with Jev 1.14.
  API access and usage are separate. Offline replay/plan/feedback need no key.
- The archive includes the MIT license, dependency and Rust library notices.

This release proposes an assignment within a host-supplied pool; the host still
discovers targets, enforces policy, reserves capacity and executes work. Native
Herdr/Orca/Stackbite adapters, automatic decomposition, DAG execution,
cost/latency optimization and feedback learning are not shipped. No global model
optimality is claimed. Windows x64 is the validated binary target.

The earlier private prototype's executable, MCP server key and typed tool names
are renamed to `switchbite` / `switchbite_*`. Update coordinator configuration
and prompts when migrating; existing client installations are not modified.
