Connect a CLI once with `switchbite codex` (also Claude, Cursor, Grok, Antigravity
and OpenCode 2). The connector keeps a stable executable, merges the user's MCP
settings, preserves unrelated settings/comments, backs up changed originals and
supports repeat setup without duplicate registrations. Open a new client session
and approve the server once if requested; coordinator instructions load through MCP.

Judge/model selection and credentials stay separate. The bundled online judge is
still Jev 1.14. This release does not add a Laya backend, model discovery or worker
execution. Existing `setup --client` and `config --client` remain print-only.

Use `--dry-run` for a preview, `--json` for automation, or `--config-file FILE` for
an explicit effective file. Malformed files, foreign name collisions and unresolved
OpenCode overrides stop setup without replacing settings.

Windows x64 public preview. MIT software; provider access and usage are separate.
