# v0.9.0-preview.6

작업자 캔버스에서 직접 카드를 추가하고 역할과 실행 순서를 정할 수 있습니다.

- 카드 머리를 드래그해 배치하고 연결점을 이어 의존 관계를 만듭니다. 연결선 선택 후 삭제할 수도 있습니다.
- **자동 정렬**, 확대·축소, **화면에 맞춤**을 제공합니다.
- **작업자 추가** 후 역할을 자연어로 입력합니다. 빈 카드들을 배치한 뒤 **이 구성으로 역할 배정**으로 조율자에게 맡길 수도 있습니다.
- 역할 배정은 카드 개수·ID·연결·배치를 유지하고 직접 입력한 역할을 보존합니다. 저장 전 입력도 배정·시작 시 포함합니다.
- 프로젝트별 초안과 실행별 위치를 브라우저에 보존합니다. 아직 시작하지 않은 작업은 실행 중에도 편집할 수 있습니다.

기본은 기존처럼 목표만 입력하는 자동 구성·실행입니다. 실제 Codex Terra high에서 구성한 두 카드가 2/2 완료됐고 Alpha 파일과 독립 검토 PASS를 확인했습니다. Rust 316개·Node 12개 테스트가 통과했습니다.

`switchbite-runtime-0.9.0-preview.6-windows-x64.zip`을 풀고 PowerShell에서 실행합니다.

```powershell
.\switchbite.exe runtime configure --manifest https://github.com/BiteFoundry/switchbite/releases/download/runtime-preview/channel-windows-x64.json
.\switchbite.exe workflow app --port 58431
```

격리된 StackBite 엔진은 0.5.75를 사용합니다. 원본 StackBite는 변경하지 않습니다.
