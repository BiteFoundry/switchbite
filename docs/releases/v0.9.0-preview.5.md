# v0.9.0-preview.5

업무만 입력하면 조율자가 작업과 의존 관계를 정하는 기본 흐름을 유지하면서, 작업 순서를 직접 지정할 수 있습니다.

- **계획을 먼저 확인하고 시작**을 켜면 작업 분해 뒤 실행을 기다립니다.
- **작업 흐름 → 작업 순서 직접 지정**에서 작업을 골라 선행 작업을 체크합니다. 적용한 관계는 도표에 표시됩니다.
- 직접 지정한 관계는 이후 재계획에서도 유지합니다. **자동으로 맡기기**로 조율자에게 다시 맡길 수 있습니다.
- 실행 중에는 아직 시작하지 않은 작업의 관계를 조정합니다. 실행·완료된 결과는 유지합니다.

실제 Codex Terra high에서 두 독립 작업을 계획한 뒤, 브라우저에서 `A → B`로 변경하고 2/2 완료와 산출물을 확인했습니다. Rust 309개·UI 10개 테스트와 clippy가 통과했습니다.

`switchbite-runtime-0.9.0-preview.5-windows-x64.zip`을 풀고 PowerShell에서 실행합니다.

```powershell
.\switchbite.exe runtime configure --manifest https://github.com/BiteFoundry/switchbite/releases/download/runtime-preview/channel-windows-x64.json
.\switchbite.exe workflow app --port 58431
```

기존 채널 사용자도 앱을 다시 실행하면 갱신됩니다. SwitchBite 전용 StackBite 엔진은 0.5.75를 사용합니다. 원본 StackBite는 변경하지 않습니다.

[사용법과 검증 기록](https://github.com/BiteFoundry/switchbite/blob/v0.9.0-preview.5/docs/manual-dependencies.ko.md).
