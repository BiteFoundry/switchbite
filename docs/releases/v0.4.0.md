Switchbite v0.4.0 public preview: a focused decision interface for coordinator agents.

**Start with one call.** Register the recommended `agent` profile, then supply a
task and factual pool to `switchbite_route`. Read status, next_action, summary and
candidate_id first. Four tools, progressive optional policy, concise text and full
structured data. No digest calculation or replay envelope is needed from agents.

- Bound expiring snapshots for advanced replay; changed task/pool/policy refuses stale data.
- Role policy presets, configurable thresholds/weights, hard estimate limits,
  producer exclusion, default tie holds and deterministic explanations.
- Context continuity and switch margins; running work is never automatically migrated.
- Two concurrent judgments by default, bounded queue/deadlines and cancellation-safe permits.
- Reused HTTP connections, static diagnostic codes, retry guidance and per-judge cooldowns.
- Imported observed-result evaluation with missing coverage and paired baseline comparisons.

Download the Windows ZIP and SHA256SUMS, verify and extract. Run
`bin/switchbite.exe setup --client claude` (or codex/cursor/grok/antigravity/opencode).
Merge the printed configuration; setup does not rewrite existing settings. Online
judging uses host-authorized TYPESAFE_API_KEY and Jev 1.14; API usage is separate.
