# SwitchBite 0.9.0 preview 1

The web app submits work to logged-in CLIs, runs independent tasks in parallel, and shows their output and waiting state. Routing and coordinator actions now run independently so a planning or review request does not stop other workers.

This Windows x64 preview includes SwitchBite and an isolated StackBite execution bridge. Existing StackBite installations are unchanged. The bridge uses the existing Codex, Claude, Cursor, OpenCode and Antigravity adapters. The real-provider qualification used Codex configured for GPT-6.1-Terra high: three parallel tasks, integration, and a fresh-session review completed all five tasks. Their output files passed exact byte checks.

## Install the automatic update channel

Download and extract `switchbite-runtime-0.9.0-preview.1-windows-x64.zip`, then run:

```powershell
.\switchbite.exe runtime configure --manifest https://github.com/BiteFoundry/switchbite/releases/download/runtime-preview/channel-windows-x64.json
.\switchbite.exe workflow app
```

The channel points to a versioned pair of executables with SHA-256 hashes. New submissions check the channel and move to the updated app when needed. Existing runs retain their recorded engine path and project base commit. `--offline` skips update checks.
