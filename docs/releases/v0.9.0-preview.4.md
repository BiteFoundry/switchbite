# v0.9.0-preview.4

실행 중 보고와 재계획을 연결했습니다.

- 웹의 **조율자에게 전달**에서 문제나 방향 변경을 보낼 수 있습니다.
- 작업자는 실행별 보고 채널로 발견 사항과 진행 불가 문제를 알립니다.
- 조율자가 보고에 답변하고 남은 작업·의존 관계·모델 배정을 조정합니다.
- 관련 없는 병렬 작업은 계속 진행합니다. 중단이 필요한 작업은 종료 확인 후 새 시도로 배정합니다.
- 보고와 결정, 계획 변경 내역을 저장하고 웹의 DAG와 함께 표시합니다.
- CLI `workflow report`와 MCP `switchbite_report`로 같은 경로를 사용할 수 있습니다.

이전 로컬 수정도 포함합니다. 조율자의 구조화된 계획 반환을 회수하고, 기본 15분 제한과 출력량 때문에 CLI 작업이 중단되던 경로를 수정했습니다.

## 설치

`switchbite-runtime-0.9.0-preview.4-windows-x64.zip`을 내려받아 압축을 풀고 PowerShell에서 실행합니다.

```powershell
.\switchbite.exe runtime configure --manifest https://github.com/BiteFoundry/switchbite/releases/download/runtime-preview/channel-windows-x64.json
.\switchbite.exe workflow app --port 58431
```

이미 채널을 설정했다면 앱을 다시 실행해 갱신합니다. 진행 중인 작업은 기록된 엔진을 유지합니다.

## 검증과 구성

실제 Codex `gpt-6.1-terra / high` 실행에서 HTML 요구사항을 Alpha에서 Beta로 변경했습니다. 조율자가 기존 결과를 보존하고 수정·독립 검토 작업을 추가해 2개에서 4개 작업으로 확장했으며, 4/4 완료와 Beta 검토 PASS를 확인했습니다. Rust 테스트 303개와 UI 테스트 9개가 통과했습니다. 이 검증의 라우터는 offline 설정이며 Jev 유료 API는 호출하지 않았습니다.

런타임에는 SwitchBite와 별도로 격리된 StackBite `0.5.75` 실행 브리지가 포함됩니다. 원본 StackBite 설치는 변경하지 않습니다. SwitchBite는 MIT이며, 엔진의 라이선스 표시는 `THIRD_PARTY_NOTICES.txt`에 보존했습니다. 실행 파일의 소스 커밋·버전·SHA-256은 버전별 manifest와 `SHA256SUMS`에 기록합니다. 런타임은 실제 CLI 검증에 사용한 소스 커밋 `4a9c6cfd044742ffaea6c7f0eef5fb2627e23e45`로 빌드했으며, 릴리스 태그는 배포 문서를 추가로 포함합니다.
