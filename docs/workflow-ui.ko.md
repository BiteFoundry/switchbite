# 로컬 워크플로 화면

워크플로 화면은 선택한 실행의 작업, 의존성, 모델 배정, 진행 상태와 다음 작업을 보여줍니다. 작업 상세를 펼치면 수락 확인 항목의 개수와 복구 횟수를 볼 수 있습니다. 화면은 2초마다 갱신됩니다.

실행 중에는 일시정지하거나 취소하고, 일시정지한 실행은 재개할 수 있습니다. 취소 후 실행 중인 작업의 정리 동작은 조율자가 워크플로의 다음 액션으로 처리합니다. 검증과 통합이 완료된 작업만 진행률에 반영됩니다.

서버는 `127.0.0.1`에서만 열리고 한 실행에 고정됩니다. 브라우저를 닫아도 실행 상태는 프로젝트에 남습니다. 서버를 종료하려면 터미널에서 Ctrl+C를 누르세요. 화면에는 설정, 작업자 원문 로그 또는 원본 영수증을 노출하지 않습니다.
